# Notifications

拥有外部邮件发送意图及其生命周期。邮件内容由调用者生成；本上下文不读取业务表，不定义成本报表规则。

## Language

**EmailDelivery**:
一次已接受的、内容不可变的邮件发送意图。具有稳定身份、原发起者、尝试代次和处置历史。
_Avoid_: 业务完成事实、实时通知、SMTP 连接

**Accepted**:
SMTP 服务器明确接受了邮件，或操作员根据外部证据确认接收。它不保证最终投递至收件箱。
_Avoid_: 已读、最终收件成功

**Unknown**:
发送开始后尚无确定结果。中断、取消、超时及回复丢失均不能证明邮件未被接受，不自动重发。
_Avoid_: 普通失败、待自动重试

**Attempt**:
一次持久记录后才开始的发送尝试。迟到结果不能改变新的尝试；人工处置必须指定观察到的代次。
_Avoid_: 聚合版本、Message-Id

**Message-Id**:
同一发送意图在所有尝试中保留的邮件头标识，仅用于调查关联，不是收件服务器的幂等保证。
_Avoid_: exactly-once 凭据、投递确认
