# 用单个定价聚合验证持久化业务任务

Pricing 是独立宿主、独立数据库的参考上下文，用于验证 NSN 的业务服务创建路径。
它的演示保本价只计算 `成本 / (1 - 费率)`，使用 decimal 并保留四位小数、远离零舍入；
例如成本 80、费率 0.2 的结果是 100。它不承担 PoS 的税费、汇率、区域、平台或批次规则。

PriceQuote 是唯一业务聚合。重算请求、领取租约和尝试历史属于执行元数据，
与聚合共享本地事务。输入版本与执行代次分开：前者拒绝旧输入，后者拒绝失去执行权的工作进程。
相同输入的重复计算不改变聚合 Version；每个新的 RequestId 仍留下一条可查询的工作记录。
首轮不自动吞并不同请求，也不承诺它们按 FIFO 执行。

当前 HTTP 仅允许带有效根操作者声明的访问令牌，执行协议只通过宿主内部 ISender 使用。
本上下文没有跨库读取 Identity 的权限或会话表。即时撤权投影、业务角色和租户授权需要后续契约，
当前验证访问令牌签名及有效期，已签发令牌的撤销时效受其过期时间约束。

执行租约使用数据库时间；计算在事务外，结果与完成状态在带锁短事务内提交。
自动重试默认三次，等待时间按本轮尝试次数递增，人工重试保留历史并开启新的预算。
首轮仅处理有限本地计算，不提供长任务心跳、检查点或外部副作用重放协议。

数据所有权与取舍见 [ADR-0019](../../../../../docs/adr/0019-context-owned-business-tasks.md)。
