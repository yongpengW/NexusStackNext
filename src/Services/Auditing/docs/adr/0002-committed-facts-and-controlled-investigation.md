# 已提交事实与受控调查

本决定取代 ADR-0001 的“无查询 HTTP、保留内部摄取 HTTP”。审计只追加、不参与业务决策的原则保留；调查人员通过显式权限保护的有界查询读取，所有环境关闭 HTTP 摄取。依赖“网关不转发”不能建立写入信任。

来源上下文在业务事务内登记最小事实，Auditing 通过已知版本的消息契约接收，以自身事务同时写 Inbox 和不可变记录。相同事件名、消息 ID 的内容不同必须拒绝，不能作为普通重复吞掉；存储故障抛出，让 broker 保留消息重投。消息身份去重覆盖 COMMIT 结果未知后的再次投递。

事实只包含来源、动作、客体标识/版本、已认证 Actor、发生时刻与追踪关联信息，不接收通用 Detail、完整请求体、设置值或说明。接收时刻由 Auditing 自己记录。追踪标识用于关联，不作为认证或授权依据。

选择受限查询而非独立数据仓库，是为了先建立可运维的完整链路；查询只读 Auditing 自己的数据，不提供跨上下文 JOIN，也不成为业务同步依赖。
