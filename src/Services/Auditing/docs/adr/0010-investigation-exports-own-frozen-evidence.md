# 调查导出保存首次接受的证据快照

AuditExport 拥有本人请求身份、首次确定的调查窗口和有界精确文本快照；来源事实与操作观察仍分别呈现。接受在读取原幂等身份之后，以单次 SELECT 冻结本上下文证据，后续生成不再分页读取活表，因而迟到消息及观察保留清理不会改变已经接受的结果。省略窗口的请求重放先比较原请求，不随当前时刻重新推导窗口。

成果交付沿用 Files 的固定候选和发布身份，发布意图之前允许取消，意图提交后只恢复同一成果。导出与操作观察不递归产生业务审计事实，但保留行审计与独立执行观察。

UploadId 与 PublicationId 分别使用原 ExportId，身份空间由 Files 协议区分，无须再维护两份随机身份。生成使用固定两分钟以内执行期限，不增加续租状态；未生成快照七天过期，已经选定的原成果仍可恢复发布，不能因快照保留期限忘记外部发布裁决。Pricing 与 Auditing 已有两个真实消费者，所以只上移相同 HTTPS 和精确文本工作簿实现，筛选及生命周期保留在所属上下文。
