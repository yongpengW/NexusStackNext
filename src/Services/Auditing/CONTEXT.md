# Auditing

审计上下文：谁在什么时候对什么完成了什么动作。它保存已提交事实，供受权人员调查。

## Language

**AuditEntry**:
一条已发生事实的记录。写入之后不可修改、不可删除。
_Avoid_: 日志、Log、记录

**Action**:
发生了什么，形如 `identity.user-registered`。它是事件的稳定名称，不是展示文案。
_Avoid_: 操作类型、事件名、动作码

**Subject**:
被操作的客体（类型 + 标识）。审计回答的是"对**什么**做了这件事"。
_Avoid_: 对象、目标、资源

**Actor**:
发起操作的人或系统。系统自身发起时为**空**，而不是某个占位帐号。
_Avoid_: 操作人、用户、执行者

**AuditFact**:
来源已经提交的最小事实。包含动作、客体及其版本、Actor、发生时刻与关联标识，不包含业务字段值。
_Avoid_: 请求尝试、操作意图、原始载荷

**Source**:
对事实负责的来源上下文。
_Avoid_: 客户端来源、用户填写的来源

**RecordedAt**:
审计接收并登记事实的时刻，与来源的发生时刻不同。
_Avoid_: 操作时间、业务提交时间
