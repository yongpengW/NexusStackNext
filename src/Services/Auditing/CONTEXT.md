# Auditing

审计与日志上下文：谁在什么时候做了什么。它是**只写**上下文——
没有任何其他上下文反向调用它，它也不会因为某个业务流程而阻塞。

## Language

**AuditEntry**:
一条已发生事实的记录。写入之后不可修改、不可删除。
_Avoid_: 日志、Log、记录

**Action**:
发生了什么，形如 `identity.user-registered`。它是事件的稳定名称，不是展示文案。
_Avoid_: 操作类型、事件名、动作码

**Subject**:
被操作的客体（类型 + 标识）。审计回答的是"对**什么**做了这件事"。
_Avoid_: 对象、目标、资源

**Actor**:
发起操作的人或系统。系统自身发起时为**空**，而不是某个占位帐号。
_Avoid_: 操作人、用户、执行者

**Detail**:
补充细节，通常是原始事件载荷。它是**证据**，不是查询字段。
_Avoid_: 备注、描述、扩展字段
