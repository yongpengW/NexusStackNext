# Scheduling

任务编排上下文：异步任务与计划任务的定义、触发与生命周期。
它只负责"**何时**触发"与"触发**结果**"，不负责"触发后做什么"。

## Language

**ScheduledTask**:
一个按固定间隔重复执行的任务定义。它知道自己上次什么时候跑的、下次什么时候该跑。
_Avoid_: 定时任务、Job、Cron 任务

**TaskCode**:
任务的稳定标识，与展示名无关。它是触发方与执行方之间的契约。
_Avoid_: 任务名、JobName

**Interval**:
两次执行的间隔。
_Avoid_: 周期、频率、Cron 表达式

**Due**:
"此刻应当执行"。一个任务只有在**启用**且**存在下次计划时刻且该时刻已到**时才算到期。
_Avoid_: 待执行、超时、过期

**Execution**:
任务被实际执行了一次。它推进下次计划时刻，并留下记录。
迟到不补跑：下次时刻从**实际执行时刻**起算。
_Avoid_: 运行、触发、调用

**TaskDue**:
"某个任务到期了"这一事实。它只表达"该跑了"，不表达"谁去跑、跑什么"。
_Avoid_: 触发事件、调度事件
