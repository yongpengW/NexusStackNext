# 私有生成成果拥有持久发布历史

Files 接受受限 Producer 的固定描述及实际字节，但完整封存不等于对 Owner 发布。候选是 StoredFile 所属状态，不是第二个聚合；不存在跨上下文事务，来源只使用 Files.Contracts 与私有 HTTPS。

UploadId/PublicationId 在 Producer 命名空间中唯一。首次描述、实际长度和摘要、归属、来源、格式/列集不可变；重放返回原 FileId 及时间，异内容拒绝。上传历史、发布历史与当前可用性分别表达，避免删除或到期后把旧成功回执误当新下载许可。终态墓碑保留，不开放“复活”或续期操作。

迁移降级也必须保留这项承诺：先在同一迁移事务取得 stored_files 排他表锁，再检查是否有已接受候选；锁等待两秒、语句五秒的有限预算保持到删除字段。存在任何候选历史就拒绝，包括尚未发布和已删除/到期的记录，否则暂存可能退化成普通可下载文件，原身份和墓碑也会丢失。并发登记先提交则降级拒绝，降级先取得锁则当前模型不能在缺列后接受登记。没有候选历史的普通文件库仍可降级；EF 多步降级可能先完成其他迁移，拒绝一项不代表整条降级链原子撤销。

Producer 从真实 TLS 客户端证书链与完整指纹映射得到，不使用普通用户令牌、CN 或转发头。明确 CA 根和中间链、clientAuth、digitalSignature、非 CA 叶、有效期及 Production Online 吊销校验都必需；框架每请求校验，不加证书认证缓存。默认关闭内部入口，开启时在 Program.cs 显式组装。它不进入公共网关或 OpenAPI，业务端口仍只能在私有网络可达。

流写入只占有界名额、磁盘与写入保护，不占数据库事务。完整实际长度/SHA-256 验证后，封存聚合及最小事实同事务保存；响应未知不能触发直接删除。既有 StorageKey 事务锁、退役标记与孤儿栅栏继续守护迟到提交。来源恢复原身份，无须猜测失败是否代表未提交。

PostgreSQL 裁决在事务锁后重读聚合及数据库时间；候选与发布身份分别串行，唯一约束兜住重复。所有执行策略尝试共享总十五秒预算，锁/语句/闲置事务也有上限。发布或清理只提交一个 StoredFile，重放不改变 Version 或行审计。Memory 使用相同公开端口在共用临界区裁决，不能宣称重启持久性。

默认首次暂存24小时，首次发布后七天，重放不续期。下载在所属截止时间立即停止，无须等待物理清理或事实额度恢复。后台按计算截止列的部分索引读取有限候选，再锁后重读；这使先成立的发布不会被旧到期扫描覆盖。每份文件单独到期并清理，CleanupCompleted 只在清理完成与事实实际提交后为 true。普通上传没有候选，不改变其期限语义。

Owner 只能通过当前有效会话访问已发布成果，根管理员不隐式越权。Producer 的委托不依赖原用户令牌续命，也不赋予下载权；Owner 的登出不丢失已接受工作。服务与系统行审计/事实 ActorId 可以为 null，不能由 Owner 推断当前操作者；发布、到期、清理事实保持固定最小内容，通过 Files Outbox 进入 Auditing。

审计导出另有已确认的撤权要求（#68/#163）：Files 按不可变 Producer `auditing`，
通过 Identity 的现有授权端口，在每次字节下载时验证 Auditing.Contracts 代码声明的导出许可。
这里变化的是生产者的访问要求，复用已认证身份即可，不增加可由请求指定的权限字段或配置。
文件归属仍先裁决，根身份不能越过他人归属；查询审计许可不隐含导出许可。
权威拒绝、故障和取消释放已打开的流，允许后把流交给 HTTP 响应。
其他生产者、元数据及删除保持原契约；不增加迁移或新的恢复机制。

代价是保留候选墓碑及两类历史身份、持久到期状态和一个计算索引，需要运维为内部 HTTPS 提供 PKI、证书轮换和可验证的吊销状态。真实 Production revoked 路径仍须用其 PKI 的可控 CRL/OCSP 验收；临时 NoCheck 旅程与 unknown-revocation 拒绝不能替代它。框架认证的请求链预算和 TLS 握手预算不同，见[研究](../../../../../docs/research/2026-10-09-private-export-service-auth.md)。

本地行为资格经真实 HTTPS、PostgreSQL、实际字节、COMMIT/进程故障和 Memory HTTP 适配器观察。Pricing 的快照、执行租约、唯一发布意图与用户下载中心属于 #150，完整组合交付属于 #151；Files 此协议不自行跨界实现那些工作。
