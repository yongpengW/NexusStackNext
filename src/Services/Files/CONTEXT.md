# Files

文件与下载中心：文件的存储、归属与分发。
其他上下文只持有 `StoredFileId`——文件的元数据、存储位置与访问策略全部归这里。

## Language

**StoredFile**:
一份已登记的文件。它持有元数据与一个**不透明的存储句柄**，不持有字节本身。
_Avoid_: 附件、资源、上传记录

**StorageKey**:
存储实现给出的句柄。它对上层**没有含义**——不要解析它、不要拼它、不要假设它是路径。
_Avoid_: 路径、URL、文件地址

**FileName**:
用户看到的文件名。它**不能包含路径分隔符**，也不能是 `.` 或 `..`。
_Avoid_: 路径、文件路径、原始名

**Owner**:
文件的归属者。公共文件没有归属者——是**空**，不是某个占位帐号。
_Avoid_: 上传人、用户、创建者

**Storage**:
真正保存字节的地方。
_Avoid_: 驱动、提供方、后端

**Download**:
把文件交给调用方的过程。它包含**授权判断**——知道标识不等于有权下载。
_Avoid_: 获取、导出、拉取
