# Files

文件与下载中心：文件的存储、归属与分发。
其他上下文只持有 `StoredFileId`——文件的元数据、存储位置与访问策略全部归这里。

## Language

**FileCandidate**:
StoredFile 所属的私有生成成果候选。登记固定描述，完整验证实际字节后才能封存；封存本身不授予下载权。
_Avoid_: 可下载文件、独立聚合、导出任务

**Producer**:
经真实 TLS 客户端证书及明确许可映射确定的服务身份。只在自己的上传/发布命名空间操作候选，不是 Owner，也不拥有下载权限。
_Avoid_: 用户令牌、CN、请求体自报来源

**UploadReceipt**:
生产者内 UploadId 对应的持久登记/封存历史。重放保留原 FileId、描述与暂存期限；到期或删除不会擦除这项历史。
_Avoid_: 当前可用性、下载凭据

**PublicationReceipt**:
生产者内唯一 PublicationId 对应的首次发布裁决。它证明发布已经成立，不证明成果现在仍可下载；重放不会续期或复活。
_Avoid_: 下载链接、当前状态、重新生成

**Availability**:
根据 Files 所属时间、发布/终态和实际存储观察得到的当前状态。CleanupCompleted 单独表示已持久确认清除字节，不能从 404 推断它。
_Avoid_: 发布回执、已物理删除

**StoredFile**:
一份已登记的文件。它持有元数据与一个**不透明的存储句柄**，不持有字节本身。
_Avoid_: 附件、资源、上传记录

**StorageKey**:
存储实现给出的句柄。它对上层**没有含义**——不要解析它、不要拼它、不要假设它是路径。
_Avoid_: 路径、URL、文件地址

**FileName**:
用户看到的文件名。它**不能包含路径分隔符**，也不能是 `.` 或 `..`。
_Avoid_: 路径、文件路径、原始名

**Owner**:
文件的归属者。当前文件默认私有，只有归属者可读取或删除；根管理员也不隐式拥有其他人的文件。
公开分发需要另行明确授权，不能把空归属当作默认公开。
_Avoid_: 上传人、用户、创建者

**Storage**:
真正保存字节的地方。
_Avoid_: 驱动、提供方、后端

**Download**:
把文件交给调用方的过程。它包含**授权判断**——知道标识不等于有权下载。
审计生产者的成果字节同时要求当前导出许可；原 FileId 和曾经授予的许可不是下载凭据。
普通上传与 Pricing 成果仍按现有本人规则，见[私有成果契约](../../../docs/private-generated-files.md)。
_Avoid_: 获取、导出、拉取

**Deletion**:
停止提供文件，并请求清除其字节。已受理只保证文件不可访问；只有确认字节清除后才算完成。
_Avoid_: 不存在、隐藏、已清空

**DeletionOrigin**:
首次成功受理删除时保留的执行关联，属于应用恢复协议。它可以未知，不能由 Owner 推断，也不提供授权。
后续清理各有自己的系统操作，仍关联原删除来源；重复删除不改写它。
_Avoid_: 当前操作人、删除权限

**RetiredStorageKey**:
已确认没有文件引用、且不再允许被文件登记使用的存储句柄。回收字节之前先确定这项事实，防止迟到的登记重新引用已清理内容。
_Avoid_: 临时路径、失效链接

**FactCapacityPolicy**:
Files 允许保留的业务事实条数、总载荷与单条载荷的额度，治理生命周期事实的接受能力。
降额不删除旧事实，也不代替文件归属或字节回收协议。
_Avoid_: 上传大小限制、文件授权、清理命令

**PolicyRevision**:
事实容量策略的单调版本。只在三个额度实际变化时推进，不改变 StoredFile 的版本。
_Avoid_: 文件版本、字节版本、请求次数

**PolicyChangeReceipt**:
Files 对一次条件策略调整的已成立裁决，保留期间同请求身份、可信操作者与同内容重放原结果。
最早保留期限不是强制删除时刻；凭据不能证明当前权限，也不表示当前策略仍相同。
_Avoid_: 当前策略、文件权限凭据、永久去重记录

**FactRecoveryReceipt**:
Files 对一次已停投事实的条件恢复裁决。保留期间相同请求身份、可信操作者及同内容重放原裁决，
不再次开放预算；它不表示中央已保存，不代表文件删除或字节清理已完成。
_Avoid_: 文件恢复结果、文件访问凭据、业务任务执行结果

**RetryRevision**:
原事实消息的恢复代次，与停投时刻共同区分不同恢复轮次。恢复只改变所属消息投递预算，
不改变 StoredFile 的版本、归属或字节状态。
_Avoid_: 文件版本、策略版本、下载次数
