# Costing

独立成本核算参考上下文，拥有成本组成、计算结果和成本事件。

## Language

**CostSheet**:
一个对象的单位采购成本、分摊运费及最近计算出的单位成本。
持久化行保存创建与最近修改的审计信息，查询通过 `audit` 返回。人工输入来自已认证主体；后台结果写入的操作者为空，保留原创建信息。相同输入或相同结果不刷新审计时间。
_Avoid_: PriceQuote、MasterPricing、库存批次

**CostCalculation**:
一次已接受的成本重算工作。输入快照与执行历史保留，结果过期时不发布成本事件；取消只停止这次计算，不撤销已接受的成本组成。
受理来源与原发起关系保留不变；当前后台执行者不冒充原发起人。
_Avoid_: ScheduledTask、消息投递、定价重算

**CostRevision**:
成本组成的输入版本。在集成事件里标识结果所依据的输入，不包含任务的执行次数。
_Avoid_: 聚合 Version、ExecutionEpoch

**CostCalculatedV1**:
某个对象、某个成本版本的完整单位成本结果，具有稳定事件标识，不携带下游费率。
_Avoid_: 增量调价命令、采购单、跨库实体

**CostDelivery**:
已计算结果从本地 Outbox 投递到 broker 的状态。Delivered 表示 broker 确认，不表示下游已经完成定价。
查询与重试只接受 `CostCalculatedV1`；同一 Outbox 中的审计消息不属于这个管理接口。
_Avoid_: 计算完成、业务全链路完成

**CostSheetCommittedV1**:
成本对象已提交的创建、输入变化或结果应用。只携带对象标识、提交版本、当前执行者与操作关联，不携带金额。
事实与所属业务状态同事务；过期结果、重复请求和空操作不产生对象变化事实。后台执行者为空，原发起人独立保留。
所属 PostgreSQL 账本按条数、UTF-8 总载荷和单条载荷原子准入。拒绝返回 `costing.audit_capacity_exhausted`，
不提交成本状态、对应任务变化或新结果消息；后台观察记失败，仍沿用既有租约、有限重试及人工重驱。
确认交付不释放容量，过期的已确认副本清理才释放；只登记既有输入快照的计划任务不占成本变化事实额度。
_Avoid_: CostCalculatedV1、任务尝试、请求成功

**ScheduledCostReceipt**:
Costing 对一个计划发生作出的持久接受或拒绝结论。接受时同时保存本地成本输入快照与任务；重投沿用原结论，不能重新解释原先不存在的目标。
_Avoid_: 消息 ACK、任务执行成功、Scheduling 的交付状态

**FactCapacityPolicy**:
Costing 自己持久保存的变化事实额度。根操作者可条件调整三个额度，业务额度已满时仍使用独立有限控制池保留调整证据。
策略管理不修改 CostSheet、CostCalculation 或成本交付状态，也不占成本变化事实额度。
_Avoid_: Platform 设置、中央审计额度、成本组成

**PolicyRevision**:
容量策略的单调版本，从 1 开始，只有额度实际改变才加 1。它不属于成本对象的 Version 或 CostRevision。
_Avoid_: 业务版本、任务代次、请求身份

**PolicyChangeReceipt**:
相同请求、可信操作者及内容可重放的原容量裁决。最早保留七天，相关控制事实还需满足已交付副本的保留条件才能清理。
仍在保留的凭据即使已到最早期限也继续用于重放或冲突判断；安全清理后不再承诺该身份永久幂等。
_Avoid_: 成本计算完成、MQ ACK、永久幂等记录

**ScheduleMessageAcceptance**:
一次有效计划消息的本地消费尝试。每次投递有独立操作，接受、稳定拒绝、重复、冲突、失败与取消分别保留。
新任务的直接来源是首次成功受理操作，上游调度操作成为其父级；当前 Actor 为系统，原发起人与计划委托独立保留。
_Avoid_: 计划裁决、成本计算完成、重投改写原回执
