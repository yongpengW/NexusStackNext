# 成本结果通过版本化事实交给定价

Costing 独立部署、独立数据库，演示单位成本为采购成本加分摊运费；数值非负、最多四位小数、合计不超过十亿。
公式不承接 PoS 的批次、税费、币种或分摊规则。用户确认本轮采用 Costing → Pricing 样板。

成本结果、执行终态和 CostCalculatedV1 在同一本地事务提交，事件标识使用原任务标识。
过期输入结束为 Superseded，不发布旧结果。事件携带完整结果及输入版本，允许消费者忽略乱序旧结果。
费率属于 Pricing，不能进入成本事件；投递失败也不能反向回滚已完成的成本核算。

HTTP 与 Pricing 样板一样只对有效根操作者令牌开放。业务角色、租户与即时撤权不由本轮演示定义。
一致性及任务实现的提取见 [系统决策](../../../../../docs/adr/0020-transactional-cost-pricing-cooperation.md)。
