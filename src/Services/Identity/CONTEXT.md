# Identity

身份与访问上下文：谁可以登录、登录后能做什么。它是所有其他上下文的**上游**——
它们不自己判断"你是谁"，只消费 Identity 给出的结论。

## Language

**User**:
一个可以登录的主体。拥有用户名、密码凭据与启用状态。
_Avoid_: 账号、账户、Account、会员

**Built-in account**:
平台自带的根管理员。它不能被禁用或删除——否则没有人能再进入系统。
_Avoid_: 超级管理员、admin、root 用户

**Role**:
一组权限的命名集合，用于批量授予。角色是**授予的载体**，不是人的属性。
_Avoid_: 用户组、Group、岗位

**Permission**:
"某个角色对某个菜单可用"这一层授权关系。它是**事实**，不是判定结果。
_Avoid_: 权限项、授权记录

**Menu**:
后台导航结构中的一个节点。它同时是权限的**挂载点**——权限授到菜单上，菜单再暴露若干 API 资源。
_Avoid_: 导航、Nav、路由、页面

**ApiResource**:
一个可被授权的 HTTP 端点（路由模板 + 方法）。它是权限推导的终点。
_Avoid_: 接口、Endpoint、资源

**Permission key**:
授权判定的最小单位，形如 `路由模板:HTTP方法`。它是 Identity 与各上下文之间的**契约**：
各上下文用同一把钥匙判断"这个请求行不行"。
_Avoid_: 权限码、权限字符串

**Platform**:
用户可登录的端（后台 / PC / 小程序 / POS）。可以是多端的组合。
注意"没有平台"与"全部平台"是两件事，**不是**同一个值。
_Avoid_: 终端、渠道、Client

**RefreshToken**:
用于换取新访问凭据的**一次性**凭据。它只能用一次；再次被使用时视为泄露。
_Avoid_: 令牌、Token、会话、Session

**Lockout**:
连续登录失败达到阈值后，在一段时间内拒绝该用户登录。
_Avoid_: 封禁、Ban、冻结

**Session version**:
用户当前接受的会话版本。撤销会话会推进这个版本，此前签发的访问凭据随之失效。
_Avoid_: 权限版本、令牌序号

**Current session decision**:
针对本次已认证主体，依据当前用户存在、启用状态和 Session version 作出的有效性与根身份结论。
它不代表普通业务权限，也不授权别的主体，不成为后续请求的永久凭据。
_Avoid_: root 声明、允许缓存、用户资料、任务执行凭据

**RolePermissionsChanged**:
"某个角色的授权集合发生了变化"这一事实。它只表达"变了"，不表达"该谁做什么"。
_Avoid_: 权限更新、刷新权限

**FactCapacityPolicy**:
本上下文允许保留的业务事实条数、总载荷和单条载荷的额度。
它治理身份事实的接受能力，不代替 Permission，也不改变已经成立的身份事实。
_Avoid_: 权限策略、账号额度、清理命令

**PolicyRevision**:
事实容量策略的单调版本。额度实际变化才推进，不改变 User、Role 或 Session version。
_Avoid_: 会话版本、权限版本、业务版本

**PolicyChangeReceipt**:
本上下文对一次条件策略调整的已成立裁决，在固定保留期间支持同请求身份与同内容重放。
它不能用来证明当前操作者有管理权限，也不表示当前策略仍等于当时的裁决。
_Avoid_: 权限凭据、当前策略、永久去重记录

**FactDeliveryRecoveryReceipt**:
所属身份业务事实或容量策略事实停止投递后，来源接受一次条件恢复的原裁决。
保留期间重放原裁决，不表示当前消息仍待投递，也不代表中央审计已保存。
_Avoid_: 当前投递状态、会话凭据、重新执行业务命令

**RetryRevision**:
所属事实的恢复代次，每次成功恢复推进；与停投时刻共同区分恢复轮次。
它不改变 User、Role 或 Session version，普通投递失败也不推进这个代次。
_Avoid_: 会话版本、业务版本、失败次数
