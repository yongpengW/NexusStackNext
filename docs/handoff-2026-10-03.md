## 换机步骤

```powershell
git clone https://github.com/yongpengW/NexusStackNext.git
Set-Location NexusStackNext
git switch dev
git pull --ff-only origin dev
dotnet restore NexusStackNext.slnx
dotnet build NexusStackNext.slnx
```

安装仓库指定 .NET 10 SDK、PowerShell 7、Git 和 GitHub CLI，恢复个人 GitHub 登录。先读 `AGENTS.md`、`CONTEXT-MAP.md`、本文件和 #64 最新评论；把“继续开发”明确交给新会话，原会话不会自动恢复目标。

`env/platform.dev`、`env/gateway.dev`、`env/test.dev` 含私密配置，故意不进入 Git。通过可信私密渠道转移或按 `env/README.md` 重新配置，不要发到 Issue、PR 或聊天。Redis 来自 platform / gateway 所连配置中心 `Redis:ConnectionString`，测试按现有环境约定注入。不要依赖旧机器的临时脚本、bin / obj 或缓存。

数据库操作先读相关持久化文档；EF 工具版本与项目 EF 10 一致。用户允许开发期初始化迁移不意味着本次已重置共享库。
